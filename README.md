# CopyMaster

Un sistema web profesional y minimalista para guardar fragmentos de código, tokens y scripts importantes.

## Tecnologías usadas
- HTML5
- CSS3 (Vanilla)
- JavaScript (Vanilla)

## Instalación
Para utilizarlo localmente y evitar errores de CORS con la inyección de componentes, ejecuta este proyecto usando un servidor local (por ejemplo, **Live Server** en Visual Studio Code).
